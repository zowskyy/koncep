# Community Projects Platform

A desktop-first web platform where people propose, discover, join, support,
fund, build, and release projects together.

Gaming is one category, not the entire product.

## Core loop

proposal -> community support -> team formation -> milestones -> funding ->
production -> release

## Supported categories

- Games
- Film and animation
- Music and audio
- Publishing
- Open-source software
- Education
- Research
- Events
- Physical products
- Community initiatives

## Initial vertical slice

A member can:

1. Create a project proposal.
2. Choose a category.
3. Describe the idea.
4. List needed roles.
5. Publish the proposal.
6. Support the proposal for free.
7. See support progress.
8. Express interest in joining the project.
